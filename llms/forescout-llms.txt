# Forescout

> Forescout Technologies is a cybersecurity company providing automated, agentless device visibility, control, and compliance across IT, OT/ICS, IoT, and IoMT environments. It exposes REST APIs for external integration through the Open Integration Module (Web API and Data Exchange plugins), the eyeSight Admin API, and the eyeInspect Command Center REST API.

## APIs

- [Forescout Web API (Open Integration Module)](https://docs.forescout.com/bundle/web-api-1-5-3-h/page/web-api-1-5-3-h.RESTful-Web-Service-Interaction.html): HTTP query/action API over the Forescout platform; JWT login at POST /api/login, then Authorization header on /api/hosts, /api/policies, /api/hostfields.
- [Forescout eyeInspect Command Center REST API](https://docs.forescout.com/bundle/eyeinspect_api_guide_v5_5_0/): OT/ICS asset inventory, alerts, vulnerabilities, and sensors; HTTP Basic auth.
- [Forescout eyeSight Admin API](https://docs.forescout.com/bundle/admin-api-1-0-h/): administrative/switch API plugin for the eyeSight platform.
